# Turing Machine Game · 图灵机规则卡

An interactive, single-page Turing machine learning game in Chinese. Explore computation through rule cards, a tape, and step-by-step machine execution.

一个中文交互式图灵机学习小游戏，通过规则卡、纸带和逐步执行，帮助孩子和家长理解计算如何由简单规则组成。

## Features

- Visual tape and read/write head with a state-based rule book.
- Arithmetic rule cards for addition, subtraction, and multiplication.
- Chinese explanations and an introduction to the story of Turing machines.
- Progress saved locally in your browser.
- Responsive layout and light/dark themes.

## Try it locally

Download `index.html` and open it in a modern web browser. No installation, build step, or backend is required. Google Fonts are loaded online; system fonts are available as fallbacks.

## Project structure

- `index.html` — the complete application, including HTML, CSS, and JavaScript.

Learning progress is stored in browser local storage and is not synced between devices.
